# Profile Page

## About
This is my profile webpage, which I created using the knowledge I gained from the module. It contains information about me, the things I love, and some of my passion projects.

## Tools Used
- HTML
- CSS
- Google Fonts

## Contents
- About Me
- Things I Love
- Passion Projects
- Contacts

## Typography
- **Libre Baskerville** for headings
- **Montserrat** for body text

I chose Libre Baskerville for the headings because I like its simple and elegant appearance. For the body text, I chose Montserrat because of its clean and modern appearance. I decided to combine serif and sans-serif typefaces because I wanted to balance a classic and modern appearance.

## Design
I chose a dark background with yellow and brown accents, along with warm white text. I wanted to maintain a dark chocolate-inspired appearance for my webpage.

## Responsive Design
I adjusted my webpage to make it look organized and readable across different screen sizes, including mobile, tablet, and desktop.
